## Governing model and reference results

The module retains the P14 cart with `d = 0.5 1/s`, known acceleration `u`, and position measurement:

```text
p_dot = v
v_dot = -d*v + u
y = p + bias + deterministic interference
xhat[k+1] = Ad*xhat[k] + Bd*u[k] + L*(y[k] - C*xhat[k])
```

For `dt = 0.02 s`, independent Python arithmetic produced:

- decay `a = 0.9900498337491681`;
- position-from-rate coefficient `b = 0.0199003325016638 s`;
- position-from-acceleration coefficient `0.0001993349966724 s^2`;
- baseline requested pole `q = exp(-2*dt) = 0.9607894391523232`;
- hand-derived gain `L = [0.06847095544452175; 0.04302293400833835 1/s]`;
- final normalized baseline error `4.077503108033036e-06` after `8 s`;
- last-second baseline RMS errors `7.1789032053976655e-06 m` and
  `1.1581117653879921e-05 m/s`;
- biased-sensor limit `true - estimated position ≈ -0.15 m`, rate error and innovation each
  below `1e-4` at the final sample;
- maximum accepted grid `5,000` steps and `5,001` finite samples.

The tests independently check `trace(Ad-LC)=2q`, `det(Ad-LC)=q^2`,
`(Ad-LC-qI)^2=0`, every plant/observer/error recurrence, known-input cancellation, exact-initial-state
limit, linear deterministic-interference scaling, and fresh-call recovery.

## Independent system-risk review

The review found one medium-severity compatibility defect. The P15 README instructed a learner to
call bare `interactive` after `launch_lesson("P15")`, but the public launcher removes the module folder
from the MATLAB path before returning. From the documented repository-root working directory, the
next command therefore could not resolve `interactive.m`, blocking the required UI flow. The README
now temporarily adds the exact P15 folder, opens the view inside `try`/`catch`, removes the folder on
both return paths, and rethrows any original error. A permanent regression retains that ordering.

The review also found one low-severity behavioral coverage gap. P15's isolated start/continue test
began with no learner history, so it could not detect a future `start P15` regression that discarded
existing completion or note records. A new temporary-repository test seeds both record classes,
starts P15, and proves that only `current` changes. No CLI implementation change was needed because
the existing behavior passed.
