# P06 retained implementation evidence — 2026-08-15

## Result and claim boundary

P06, **Tune a PID by Observing Each Term**, is implemented as a complete
deterministic learning slice on branch `agent/p06` at base commit `dc7e620`. A
transparent RK4 model shows a proportional force from present error, an integral
force from accumulated error, and derivative-on-measurement damping on a 1 kg
carriage tracking `1 m` against a constant `-1 N` load. Independent `Ki` and `Kd`
sweeps expose offset/overshoot and damping/effort tradeoffs. The broken case
reverses derivative polarity to create negative damping; recovery restores the
opposing sign before retuning.

Neither MATLAB nor Octave was available on `PATH`. MATLAB source, assertions,
figures, and UI were authored and statically inspected but did not execute in a
MATLAB runtime. Python tests execute independent reference arithmetic for the
documented equations; they do not execute `model.m`. The manifest's `simulated`
evidence level identifies deterministic simulation content, not MATLAB runtime,
rendered UI, numerical-fidelity, bench, HIL, field, or production evidence.

## Positive, negative, recovery, compatibility, and resource coverage

- Positive/reference cases: deterministic equality, initial P/I/D/acceleration,
  controller sum, plant force residual, constant-reference derivative identity,
  steady integral load balance, an independently factored stable three-pole
  position/velocity/integral trajectory, both independent levers, and reference RK4
  values.
- Limiting cases: P+D offset `-Fload/Kp = 0.25 m`, zero controller/load equilibrium,
  inactive integral accumulator growth, zero-Kd derivative-sign invariance, and
  coarse/fine RK4 endpoint convergence.
- Negative/malformed cases: nonfinite, nonreal, nonscalar, negative gain,
  nonpositive duration/interval, invalid derivative sign, and out-of-contract
  gains, load, horizon, resolution, response, and sample requests are rejected.
- Broken/recovery: `D = +Kd*v` creates `-2.5 N*s/m` effective damping and position
  magnitude over `100 m`; restoring `D = -Kd*v` recovers positive damping and a
  bounded response before retuning.

  final interval, maximum 20,001 samples, larger-grid rejection, dimensionless
  rate-step limit, state response cap, and bounded UI gain ranges.

  asynchronous work, and performs no random, file, network, service, or process I/O.
- Compatibility: only base MATLAB arithmetic, `arguments`, and the `uifigure` /
