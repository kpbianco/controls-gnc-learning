# P07 retained implementation evidence — 2026-08-15

## Result and claim boundary

P07, **See Stability Margin in Time and Frequency**, is implemented as a complete
deterministic learning slice on branch `agent/p07` at base commit `70be5eb`. A
transparent base-MATLAB model connects the closed-loop state equations
`y' = v`, `v' = a-b*v`, and `tau*a' = K*(r-y)-a` to the open loop
`L(s) = K/[s(s+b)(tau*s+1)]`, with `b = 1/s`. Independent sweeps move loop gain
`K` and actuator lag `tau`. The broken case applies `K = 4 1/s^2` after assuming
an instantaneous actuator, then exposes negative margin and a growing response
when the actual actuator has `tau = 0.5 s`; recovery retains the lag and reduces
gain below the exact critical value.

Neither MATLAB nor Octave was available on `PATH`. MATLAB source, assertions,
figures, and UI were authored and statically inspected but did not execute in a
MATLAB runtime. Python tests execute independent margin arithmetic and RK4
reference equations; they do not execute `model.m`. The manifest's `simulated`
evidence level identifies deterministic simulation content, not MATLAB runtime,
rendered UI, MATLAB numerical fidelity, bench, HIL, field, or production evidence.
