## Independent risk-review repair

The oscillatory checks previously used only `initialVelocity = 0`. A defect in the
initial-condition phase coefficient or its velocity mapping could therefore evade
the special one-period and envelope checks. The bounded repair adds a quarter-cycle
case with `x0 = 1.25 m` and `v0 = -0.75 m/s`, checking the exact initial state and
independently derived terminal displacement and velocity. A permanent Python test
guards the presence of that executable MATLAB regression. MATLAB execution remains
unperformed, so this closes the retained test-definition gap without claiming
runtime evidence.
