# P05 retained implementation evidence — 2026-08-14

## Result and claim boundary

P05, **Close a Loop with Proportional Control**, is implemented as a complete
deterministic learning slice in the `agent/p05` worktree at base commit
`a966ca7f9c8b8d28330fefa7a58ba11e6548bbed`. The module closes a transparent
first-order plant around `u = Kp*(r-y)`, exposes the pole, proportional offset,
response speed, and effort tradeoff, and reverses feedback polarity as its broken
case before restoring subtraction as recovery.

interval propagation, assertions, figures, and UI were authored and statically
inspected but did not execute in a MATLAB runtime. The manifest's `simulated`
evidence level describes deterministic simulation content; it is not a MATLAB
execution or numerical-fidelity claim. This evidence does not establish MATLAB
runtime behavior, rendered UI behavior, MATLAB numerical fidelity, instructional
efficacy, bench, physical hardware, HIL, RT1/RT2, Unreal, field, playtest, staging,
signing, release, deployment, or production validation.

## Independent audit repairs

- Exact interval propagation now evaluates the constant-input term with `expm1`
  instead of subtracting nearly equal equilibrium-scale values. The zero-pole ramp,
  a nontrivial `1+1e-10` pole, and the closest representable `1±eps` neighbors are
  all retained as executable MATLAB assertions and permanent source guards.
- Both gain cases use `dt = 0.005 s`, and both plant-time-constant cases use
  `dt = 0.005 s`; checks also assert equal actual maximum intervals, so each pair
  changes exactly one conceptual input.
- The reversed-sign case dynamically checks `u = 2*(1+y)` over the whole trajectory
  and checks the plant residual `tau*y' - (-y+G*u)` rather than relying only on
  source text.
- A named display-resolution bound requires `|p|*maxInterval <= 0.1`; interactive
  previews adapt their output interval inside that bound. A separate positive-growth
  exponent and output bound prevents explosive requests from exhausting the learning
  view before allocation or propagation.
- `interactive.m` now captures the resolved P05 `model` function handle for the
  callback lifetime. A still-open P05 window therefore does not depend on later
  global path cleanup or name-cache changes to select its model.
- `run_checks.m` now propagates a state initialized at the reference while the plant
  still needs feedback effort to hold it. The full trajectory must equal the
  independent homogeneous-plus-forced solution, with zero initial command and the
  expected `-1 m/s` initial plant rate; a permanent P05 test retains this executable
  MATLAB regression.
