# P08 retained implementation evidence — 2026-08-15

## Result and claim boundary

P08, **Reject a Disturbance with Feedback**, is implemented as a complete,
deterministic learning slice on branch `agent/p08` from target baseline `a2a6675`
(the active contract retains the original portfolio baseline `58c96ae`). The
transparent base-MATLAB plant is `tau*y' = -y + u + d`, with `tau = 1 s` and
`u = -K*(y+bias)`. The lesson separates absolute plant filtering from feedback's
additional rejection, sweeps feedback gain and disturbance frequency independently,
and breaks the honest-sensor assumption before recovering through sensor correction.

Neither MATLAB nor Octave was available on `PATH`. MATLAB source, assertions,
figures, and UI were authored and statically inspected but did not execute in a
MATLAB runtime. Python tests execute independent equilibrium, frequency, limiting-
case, exact step-response, sinusoidal-transient, RK4-history, and onset-crossing
arithmetic; they do not execute `model.m`. The
manifest's `simulated` evidence level identifies deterministic simulation content,
not MATLAB-runtime, rendered UI, MATLAB numerical fidelity, bench, HIL, field, or
production evidence.
