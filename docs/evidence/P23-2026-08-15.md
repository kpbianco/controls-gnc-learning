## Governing model and deterministic input contract

P23 treats P22's bounded lateral-acceleration request as a deterministic square wave. The explicit physical
chain is

```text
u_limited = clip(u, -a_max, +a_max)
tau_a * da/dt + a = u_limited
tau_s * dy/dt + y = a
y_reported = y + bias
```

Every held interval `[t(k-1),t(k)]` uses command sample `k-1` and the exact first-order decay
`exp(-dt/tau)`; an explicit reversal-boundary invariant prevents endpoint-command anticipation. For positive unequal time constants,
the cascade coefficient is `tau_a/(tau_a-tau_s)*(alpha_a-alpha_s)`; close unequal time constants use an
algebraically equivalent `expm1` form to avoid subtractive cancellation, and equal time constants use the
finite limit `(dt/tau)*alpha`. If a positive time constant is below the exponential underflow scale, the
mathematical `x*exp(-x)` coefficient limit is evaluated as zero rather than the nonfinite floating-point
product `Inf*0`. Zero time constants remain explicit ideal-device branches.

Accepted inputs are actuator and sensor time constants `0–1.5 s`, command half-period `0.1–4 s`, command
amplitude `1–80 m/s^2`, actuator limit `5–100 m/s^2`, sensor bias `-20–20 m/s^2`, time step `0.002–0.05 s`,
and duration `4–20 s`. Duration and half-period must align with the time grid. All derived-grid and
5,001-sample resource checks run before histories are allocated.
