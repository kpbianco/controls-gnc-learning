## Failure, isolation, compatibility, and resource coverage

- Positive and limiting cases: deterministic repeatability, exact integrator area,
  bounded monotone first-order response, 63.2% one-`tau` value, zero input, amplitude
  scaling, and time-constant/equilibrium independence.
- Negative and malformed cases: nonfinite, nonreal, nonscalar, zero/nonpositive time
  constant, duration, and calculation interval are rejected.
- Resource bounds: the model caps the deterministic grid at 20,001 samples; the boundary
  is accepted and larger requests raise `P02:TooManySamples`.
- Grid lifetime and interval semantics: the endpoint is included exactly, timestamps are
  strictly increasing for a decimal integer-ratio regression, and horizons shorter than
  the requested interval report the actual endpoint-clipped Euler interval.
- Broken/recovery comparison: `dt/tau = 3` creates alternating Euler divergence while
  the exact response remains bounded, and returning to a resolving interval restores a
  close Euler/reference match.
- Isolation: model execution has no external I/O or mutable persistent state; learner CLI
  tests execute in temporary repository fixtures.
- Compatibility: only transparent base-MATLAB operations and existing project UI APIs
  are used. Actual MATLAB release compatibility remains unverified without a runtime.
- Timeout and cancellation tests are not applicable to the bounded synchronous pure
  calculation: it starts no process, request, timer, or cancellable operation.
- Data migration, scoring, backup/restore, and service smoke gates are not applicable;
  P02 changes no persisted schema, score, database, or service.
