## Governing model, assumptions, and units

For target-to-interceptor relative position `r` and relative velocity `v_rel`:

```text
R         = sqrt(r_x^2+r_y^2)                                  [m]
Vc        = -dot(r,v_rel)/R                                     [m/s]
lambdaDot = (r_x*v_rel_y-r_y*v_rel_x)/R^2                       [rad/s]
a_cmd     = N*max(Vc,0)*lambdaDot                               [m/s^2]
a_applied = min(max(a_cmd,-a_max),a_max)                        [m/s^2]
psi(k+1)  = psi(k)+(a_applied/interceptor_speed)*dt             [rad]
```

The interceptor speed is fixed at `300 m/s`; acceleration is normal to velocity. The target starts at
`[5000,600] m`, has zero along-track speed, and a configurable constant crossing speed. The baseline uses
`N=3`, target crossing speed `60 m/s`, acceleration limit `80 m/s^2`, `dt=0.02 s`, horizon `25 s`, and
capture radius `5 m`. Positions use the updated heading over each full discrete interval. This defines the
educational sampled recurrence; it is not a continuous-time solver claim.

The first segment/circle root is retained when relative motion enters the capture radius between samples.
Miss distance uses the closest point on every piecewise-linear relative-motion segment. After closing speed
becomes nonpositive, `max(Vc,0)` makes the PN command zero. Accepted inputs are N `0–8`, crossing speed
`-150–150 m/s`, acceleration authority `5–120 m/s^2`, step `0.005–0.1 s`, horizon `5–40 s`, an integral
time grid, and no more than 5,001 allocated samples. All caps are checked before history allocation.
