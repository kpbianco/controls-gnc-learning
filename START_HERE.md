# Start here

This is the Controls, State Estimation, Guidance, and Navigation interactive MATLAB track. Run `./bin/learn status`, then
`./bin/learn start`. P01 is the implemented reference, P02-P13 are implemented, and P14-P24 remain
intentional scaffolds that map one-to-one to Portfolio Control batches. A learner session follows read → visualize → move one lever
→ visualize the change → read/explain, then a broken case, checks, and teach-back.

Use `docs/CURRICULUM_AUDIT.md` for the complete phase and batch map.
